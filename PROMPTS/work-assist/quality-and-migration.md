## コード構造・版管理
名前と構造で役割を示す。既存規約優先。版番号・対象を混同しない。変更履歴は既存CHANGELOG等へ実差分で集約。

- 役割が読み取れる箇所に説明コメントを重ねない。長い処理の区分が見えにくい場合だけ入力解析/検証/変換/永続化などを短く示す
- コメントは「なぜその制約・例外・非自明な選択か」に限定。Whatの再述はしない
- 共通化は意味と変更理由が共通する処理だけ。類似だけでは統合しない
- 短さより読みやすさと既存規約
- 単なるファイル編集に版番号を付けない。SemVer: MAJOR=互換破壊 / MINOR=後方互換の機能追加 / PATCH=後方互換の修正。製品/API/依存/データ形式/ファイル名の版を混同しない

### 残留物
対象: 実害・保守負担がある重複/完全代替できる旧実装/不要な注意書き・経路案内/未使用コード/古いコメント/デバッグ出力/一時ファイル
1. grep・呼び出し元・設定・テストに加え動的登録/反射/外部入口を確認。参照が残る物は消さない
2. 履歴・コメントから意図確認。不明は削除せず提案
3. 小さく変更して都度検証。動作・互換に影響する大規模削除は提案に分ける
(自作予定書・cache・一時物は[workflow](workflow.md)の後片付け)

## 効率化
効果を測れる変更は同条件で前後比較。正確性・安全性・保守性を損なう短縮はしない。

- 調査: 同じファイル/ログ/URLを繰り返し読まず差分と関連箇所を見る
- 計算: ループ内で不変の値/正規表現準備/同一JSON解析をループ外へ
- I/O・通信: 繰り返し読み書き/APIを一括化。並行は依存と順序を確認してから
- データ・キャッシュ: 不要コピー/変換を減らす。キャッシュは更新条件/期限/破棄を決めてから
- 避ける: 効果のないマイクロ最適化/失効条件のないキャッシュ/競合未検証の並列
- 例: Pythonは正規表現を先にcompile / JS・TSは独立fetchをPromise.all / C・C++・Rustは不要な大容量コピーを避け所有権・寿命・エラー経路を保つ

## 言語・基盤（種の統一と分岐）
目的: 新規・改修で言語を散らさず、検証可能性とAI/ツール支援の効く種へ寄せる。既存資産を壊すための置換はしない。

### 選択材料（共通）
既存資産と変更範囲 / 対象環境 / ビルド・配布 / 必要ライブラリ / 性能 / 保守 / 移植リスク / 検証経路の有無。互換が崩れる・検証経路が無い場合は採用せず理由を1行。

### Android（アプリ層と低レイヤーを分ける）
| 層 | 既定候補 | 備考 |
|---|---|---|
| アプリUI・業務ロジック | **Kotlin 優先** / React Native(TS) | ネイティブAPI・権限・ライフサイクルを先にKotlinで設計すると手戻りが減る |
| RN採用時 | TypeScriptのまま | JSへ戻す工程は検証用。互換確認済みならTS維持 |
| 低レイヤー（NDK・高負荷計算・専用同期） | 必要時のみ C/C++。**Rustを既定にしない** | 同期/FFI境界の重みがUIや起動を悪化させ得る。採用時は境界を小さくし前後測定 |
| グラフィックス | 要件に応じ Vulkan 等 | 既存エンジン/依存を優先 |

### 一般（非Android・新規モジュール）
AIが扱いやすく型と検証が効く順の目安（強制ではない）:
1. **TypeScript** — フロント/RN/ツール連鎖、型で失敗を前倒し
2. **Python** — スクリプト・AgentKit系・データ処理（この系統の検証環境で動きやすい）
3. **Go** — CLI/サービス、依存が少なくレビューしやすい
4. **Kotlin** — JVM/Android以外でも共有ロジック
5. **Rust** — メモリ安全性・性能境界が主目的の新規/大幅改修。関数・モジュール・FFIごとに移し都度テスト
6. C/C++ — 既存コード・ABI固定・上記が使えない場合
7. Goose 等 — 実験・特殊用途。種の統一より外す判断を先に

Zig はツールチェインと検証経路が揃うときのみ。言語を増やす前に「既存種で足りるか」を確認する。

### JS / TS
- JS由来: TS化して型付与（原則ツール。手作業なら箇所と理由）→ 型検査/Lint/テスト/ビルド → 必要なら元 target に合わせて差分確認
- 検証のみなら checkJs/JSDoc との費用対効果を比べるが、指定工程は置き換えない
- 補助: AgentKit `compile-ts`（既存 tsc のみ。自動 install しない）
