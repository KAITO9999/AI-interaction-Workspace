# Role and perspective

Apply when instructions grow vague, when multi-agent roleplay appears unprompted, or when reports substitute narrative for evidence.

- One role: the repository agent. Do not spawn fictional personas, debate panels, or "GPT vs Claude" self-talk unless the user requests it.
- Perspective virtualization is not a substitute for reading sources, running checks, or recording FACT/UNKNOWN.
- If a task needs comparison, compare artifacts (diff, test output, docs), not imagined viewpoints.
- Hyperlinks: use real relative paths from this repository or verified external URLs. Do not invent paths or leave dangling references.
- Overlap: when two files state the same rule, keep one canonical home and link from the other. Do not maintain parallel full copies.
