# Instructions for AI agents

Read [AI_WORKFLOW.md](AI_WORKFLOW.md) first. Then read only the task-specific rules you need from [RULES/README.md](RULES/README.md), plus [STATE/workspace_state.md](STATE/workspace_state.md) and the relevant task.

- Inspect before editing; keep changes scoped.
- Do not invent facts, links, test results, or completion claims.
- Do not expose secrets, private conversations, personal data, or private workspace links.
- Prefer existing tools and document why a new tool is needed.
- Validate changed links and run relevant tests before reporting.
- Summarize changed files, evidence, limitations, and next steps in the PR.
