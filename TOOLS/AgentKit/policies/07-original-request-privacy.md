# Original request and private workspace policy

The original planning request should be retained verbatim in a private project workspace or private notes repository, not copied into this public repository. This public repository may hold only a redacted summary, versioned technical decisions, and a pointer to the private source.

Recommended private record fields:
- Original text, unchanged
- Date/time and project/version
- Decisions derived from it, with links to implementation files
- Deferred items and reasons
- A change log that distinguishes user requirements from AI-proposed implementation choices

Do not store credentials, account identifiers, personal secrets, or connector tokens in the request record. Keep the source private and use the public policy files as implementation documentation.
